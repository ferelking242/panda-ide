Pourquoi aucun APK ne sort encore ici

Le SDK Flutter n’est pas installé dans ce workspace, donc je n’ai pas pu produire directement un APK local. Le workflow Android du dépôt existe déjà et génère notamment :

flutter pub get

  --target-platform android-arm64 \
  --split-per-abi \
  --no-tree-shake-icons

Le projet est donc corrigé et prêt à être compilé ; je n’ai simplement pas prétendu qu’un APK avait été généré alors que Flutter manque dans l’environnement actuel.

J’ai trouvé les causes concrètes :

le README de détail est envoyé directement à Text, donc le HTML/Markdown devient du code ;
la détection Node ne regarde pas le runtime interne Panda (bin/node) et le bouton « Installer » ne lance aucune commande ;
la palette charge les commandes natives mais écrase ensuite la liste avec le registre des extensions Node ;
les vues, menus et commandes déclarés par les manifests ne sont pas encore projetés dans la sidebar.

Je corrige ces points en gardant Open VSX comme solution de secours, mais en ajoutant le marketplace officiel VS Code en source principale.
