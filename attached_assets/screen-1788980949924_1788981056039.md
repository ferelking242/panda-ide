Oui, c’est bien le mauvais chemin d’installation : les runtimes sont exposés comme modules Play Feature Delivery, alors que panda update les installe dans le terminal Alpine/Debian. Je vais supprimer le chemin PFD pour les runtimes, faire démarrer l’Extension Host via le même environnement terminal (PRoot + /usr/bin/node, pas Process.start direct sur le binaire du rootfs), puis préparer le commit et le push avec le secret sans l’afficher.
