Panda IDE — Embedded Browser complet avec CEF

Objectif

Ajouter à Panda IDE un véritable navigateur intégré accessible depuis la sidebar.

Le navigateur doit :

- être une page native du Workbench Panda IDE ;
- avoir ses propres onglets ;
- avoir navigation complète ;
- supporter ChatGPT, Claude, GitHub, YouTube et les applications web modernes ;
- supporter JavaScript moderne, WebGL, WebGPU, WebRTC, WASM, Service Workers, IndexedDB, cookies, localStorage, téléchargements, etc. ;
- utiliser Chromium via CEF ;
- être rendu directement dans Panda IDE ;
- ne jamais utiliser VNC, streaming vidéo, screenshots ou contrôle d'une fenêtre externe ;
- utiliser le GPU lorsque disponible ;
- rester séparé du reste de l'IDE ;
- pouvoir fonctionner indépendamment de Panda AI.

5. Runtime séparé du projet

Le runtime CEF doit être global à Panda, pas copié dans chaque projet.

Mauvais :

projectA/
  cef/

projectB/
  cef/

projectC/
  cef/

Correct :

Panda
└── runtime/
      └── cef/

Tous les projets Panda utilisent le même runtime.

Cela économise énormément d'espace disque.

Objectif :

aucun comportement VNC-like.

Interdit :

browser → screenshot → Flutter → display

Interdit :

browser externe → capture → Panda

Le rendu doit être :

CEF
 ↓
Chromium compositor
 ↓

Le travail n'est terminé que lorsque ce scénario fonctionne :

Fresh Panda installation
        ↓
click Browser
        ↓
Panda détecte CEF absent
        ↓
Download Runtime
        ↓
Install
        ↓
Start CEF
        ↓
Browser appears directly inside Panda
        ↓
open ChatGPT
        ↓
login
        ↓
open Claude in another tab
        ↓
install/test extension
        ↓
open DevTools
        ↓
open Panda project
        ↓
run local dev server
        ↓
open localhost in Preview

Et tout cela doit se produire dans Panda, sans fenêtre Chrome externe et sans VNC/screenshot streaming.

Règle fondamentale

CEF est une dépendance runtime téléchargeable, pas une dépendance lourde empaquetée dans l'application Panda principale.

Le navigateur est embarqué, mais son moteur est téléchargé séparément.

L'interface Panda doit rester légère ; le runtime Chromium n'est téléchargé que lorsque l'utilisateur utilise le Browser/Preview pour la première fois.
